# ROI Calculation Examples

Practical examples of ROI calculations for common business scenarios, demonstrating methodology and presentation techniques.

---

## Basic ROI Formula

```
ROI = (Net Benefit / Cost of Investment) × 100
```

Where Net Benefit = Total Benefits − Total Costs.

## Example 1: Marketing Campaign ROI

### Scenario
A digital marketing campaign costs $50,000 and generates $180,000 in attributable revenue over 6 months.

### Calculation

| Metric | Value |
|--------|-------|
| Campaign cost | $50,000 |
| Revenue generated | $180,000 |
| COGS on revenue (40%) | $72,000 |
| Gross profit from campaign | $108,000 |
| Net benefit | $108,000 − $50,000 = $58,000 |
| **ROI** | ($58,000 / $50,000) × 100 = **116%** |

### Key Consideration

Use gross profit, not revenue, as the benefit. Revenue-based ROI inflates the return by ignoring the cost of goods sold.

### Attribution Note

Marketing ROI depends heavily on attribution model:
- **Last-click**: 100% credit to last touchpoint before conversion
- **Multi-touch**: Distributed credit across all touchpoints
- **Incrementality test**: Compare exposed vs. unexposed groups

Different models can yield dramatically different ROI figures for the same campaign.

## Example 2: Software Implementation ROI

### Scenario
Implementing a CRM system for a 50-person sales team.

### Cost Analysis

| Cost Category | Year 1 | Year 2 | Year 3 |
|--------------|--------|--------|--------|
| Software licenses (50 × $150/mo) | $90,000 | $90,000 | $90,000 |
| Implementation services | $60,000 | $0 | $0 |
| Training | $15,000 | $5,000 | $5,000 |
| Data migration | $20,000 | $0 | $0 |
| Internal project management | $25,000 | $0 | $0 |
| **Total Cost** | **$210,000** | **$95,000** | **$95,000** |

### Benefit Analysis

| Benefit | Basis | Year 1 | Year 2 | Year 3 |
|---------|-------|--------|--------|--------|
| Sales productivity (10% time saved × 50 reps × $100K salary) | Process study | $250,000 | $500,000 | $500,000 |
| Improved win rate (2% increase × $10M pipeline) | Industry benchmark | $100,000 | $200,000 | $200,000 |
| Reduced churn (5% improvement × $2M at-risk revenue) | CS analysis | $50,000 | $100,000 | $100,000 |
| **Total Benefit** | | **$400,000** | **$800,000** | **$800,000** |

Note: Year 1 benefits are reduced (ramp-up, partial year of adoption).

### ROI Summary

| Metric | Value |
|--------|-------|
| 3-Year Total Cost | $400,000 |
| 3-Year Total Benefit | $2,000,000 |
| 3-Year Net Benefit | $1,600,000 |
| **3-Year ROI** | **400%** |
| Payback Period | ~7 months |

## Example 3: Process Automation ROI

### Scenario
Automating a manual invoice processing workflow.

### Current State

| Metric | Value |
|--------|-------|
| Invoices processed per month | 2,000 |
| Time per invoice (manual) | 15 minutes |
| Total hours per month | 500 hours |
| Cost per hour (fully loaded) | $35 |
| Monthly processing cost | $17,500 |
| Error rate | 4% |
| Cost per error to correct | $50 |
| Monthly error cost | $4,000 |
| **Total monthly cost** | **$21,500** |

### Future State (Automated)

| Metric | Value |
|--------|-------|
| Time per invoice (automated) | 2 minutes (exceptions only) |
| Total hours per month | 67 hours |
| Monthly processing cost | $2,333 |
| Error rate | 0.5% |
| Monthly error cost | $500 |
| **Total monthly cost** | **$2,833** |

### ROI Calculation

| Metric | Value |
|--------|-------|
| Monthly savings | $21,500 − $2,833 = $18,667 |
| Annual savings | $224,000 |
| Automation implementation cost | $150,000 |
| Annual maintenance cost | $20,000 |
| Year 1 net benefit | $224,000 − $150,000 − $20,000 = $54,000 |
| **Year 1 ROI** | ($54,000 / $170,000) × 100 = **32%** |
| Year 2+ annual ROI | ($224,000 − $20,000) / $20,000 × 100 = **1,020%** |
| Payback period | $150,000 / ($18,667/mo) = **8 months** |

## Presenting ROI to Stakeholders

### Best Practices

1. **Show your math**: Present the assumptions and methodology, not just the final number
2. **Use conservative estimates**: Understating benefits builds credibility
3. **Include sensitivity analysis**: "Even if benefits are 50% lower than projected, ROI is still 80%"
4. **Separate hard and soft benefits**: Hard (measurable) vs. soft (estimated) — hard benefits carry more weight
5. **Include payback period**: Executives care about how quickly the investment pays for itself
6. **Present multiple scenarios**: Best case, base case, worst case
