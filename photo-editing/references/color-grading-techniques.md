# Color Grading Techniques

Apply creative color grades to photographs for mood, style, and visual consistency.

---

## Color Theory for Photography

### Color Wheel Relationships

| Relationship | Description | Photographic Use |
|-------------|-------------|-----------------|
| Complementary | Opposite on wheel (blue/orange) | Maximum contrast, cinematic |
| Analogous | Adjacent on wheel (blue/teal/green) | Harmonious, natural |
| Triadic | Equal spacing (red/blue/yellow) | Vibrant, balanced |
| Split-complementary | Base + two adjacent to complement | Dynamic, less intense |

### Color Psychology

| Color | Mood/Feeling | Photography Genre |
|-------|-------------|------------------|
| Warm (orange/yellow) | Nostalgia, comfort, joy | Golden hour, lifestyle |
| Cool (blue/teal) | Calm, melancholy, professional | Corporate, moody |
| Green | Natural, fresh, organic | Nature, wellness |
| Red | Passion, energy, danger | Fashion, editorial |
| Desaturated | Vintage, serious, timeless | Documentary, fine art |
| High contrast | Drama, power | Editorial, fashion |

## Popular Color Grades

### Orange and Teal (Cinematic)

**Lightroom Settings:**
| Adjustment | Value |
|-----------|-------|
| Color Grading — Shadows | Hue: 200 (teal), Sat: 25-40 |
| Color Grading — Highlights | Hue: 35 (orange), Sat: 20-35 |
| HSL — Orange Sat | +15 to +25 |
| HSL — Aqua/Blue Sat | +10 to +20 |
| Calibration — Blue Primary Hue | Shift toward teal (-20 to -40) |

### Film/Vintage Look

| Adjustment | Value |
|-----------|-------|
| Tone Curve — Blacks point | Lift to 10-20 (faded blacks) |
| Tone Curve — Whites point | Pull down slightly (muted highlights) |
| Color Grading — Shadows | Slight green or blue tint |
| Grain | Amount: 25-40, Size: 25, Roughness: 50 |
| Vibrance | -15 to -25 |
| Clarity | -5 to +5 |

## Advanced Techniques

### Split Toning with Luminosity Masks
1. Create luminosity masks (highlight, midtone, shadow selections)
2. Apply different Color Balance adjustments to each
3. Fine-tune mask feathering for smooth transitions
4. Result: Independent color control for each tonal zone

### Color Harmonization in Composites
- Match color temperature across all elements
- Use Color Lookup adjustment layer for unified grade
- Apply same color grade to all layers
- Check skin tones remain natural

## Consistency Across a Series

### Workflow for Consistent Grades
1. Edit hero image first (invest time perfecting the grade)
2. Save as preset (Lightroom) or action (Photoshop)
3. Apply to entire series
4. Quick review: adjust exposure/WB per image
5. Spot check: verify skin tones, key colors across set
6. Export with consistent settings

### What Varies vs What Stays Constant

| Varies Per Image | Stays Constant |
|-----------------|----------------|
| Exposure | Tone curve shape |
| White balance | HSL adjustments |
| Local adjustments | Color grading |
| Crop | Calibration |
| Spot removal | Sharpening settings |
