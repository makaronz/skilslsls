# Focus Stacking

Achieve front-to-back sharpness through multi-shot focus combination.

---

## Why Focus Stacking

At 1:1 magnification:
| Aperture | DOF |
|----------|-----|
| f/2.8 | 0.3mm |
| f/8 | 0.9mm |
| f/16 | 1.8mm (diffraction) |

Beyond f/11-16, diffraction softens images. Stacking is the only way to get full sharpness.

## Capture Methods

### Focus Rail (Best)
1. Mount camera on focusing rail + tripod
2. Focus on nearest point
3. Move rail forward by step size
4. Shoot frame, repeat until farthest point covered

## Step Size Guide

| Magnification | f/8 Step | Shots for 10mm subject |
|--------------|---------|----------------------|
| 1:1 | 0.3mm | 20-35 |
| 2:1 | 0.1mm | 65-100 |
| 5:1 | 0.02mm | 330-500 |

## Photoshop Method
1. File > Scripts > Load Files into Stack
2. Auto-align layers
3. Edit > Auto-Blend > Stack Images
4. Flatten and clean artifacts

## Tips
- Shoot at f/5.6-f/8 (sharpest), stack for DOF
- Use flash for consistent exposure per frame
- Electronic shutter eliminates vibration
- Shoot more frames than needed (overlap is good)
- Process all frames identically before stacking
