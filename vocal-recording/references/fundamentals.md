# Vocal Recording Fundamentals

Core concepts for capturing high-quality vocal recordings in studio and field environments.

---

## Microphone Selection

### Microphone Types for Vocals

| Type | Characteristic | Best For | Example |
|------|---------------|---------|---------|
| Large Diaphragm Condenser | Detailed, wide frequency response, sensitive | Studio vocals, podcasts, voiceover | Neumann U87, AKG C414, AT2020 |
| Dynamic | Durable, less sensitive to room noise | Live performance, loud vocalists, untreated rooms | Shure SM7B, Electro-Voice RE20 |
| Ribbon | Warm, natural, smooth high end | Jazz, classical, vintage character | Royer R-121, AEA R84 |
| Small Diaphragm Condenser | Accurate, fast transient response | Choir, ensemble, acoustic performance | Neumann KM184, Rode NT5 |

### Polar Pattern Selection

| Pattern | Characteristics | Use Case |
|---------|----------------|----------|
| Cardioid | Picks up from the front, rejects sides and rear | Standard vocal recording, isolating the singer |
| Figure-8 | Picks up front and rear, rejects sides | Two singers facing each other, ribbon mics |
| Omni | Picks up equally from all directions | Natural room sound, ambient recording |
| Supercardioid | Narrower than cardioid, slight rear pickup | Isolating vocals in noisy environments |

## Signal Chain

### Optimal Recording Chain

```
Microphone → Cable → Preamp → Compressor (optional) → A/D Converter → DAW
```

### Preamp Considerations

| Preamp Type | Sound Character | Best Pairing |
|-------------|----------------|-------------|
| Transparent/Clean | Accurate, neutral, adds no color | Condenser mics for modern pop, podcast |
| Tube | Warm, harmonically rich, slight saturation | Dynamic mics, adding body to thin sources |
| Transformer-based | Colored, punchy, slight compression | Ribbon mics, rock and soul vocals |

### Recording Levels

- Target input level: -18 dBFS to -12 dBFS peak
- Leave at least 6 dB of headroom for dynamic passages
- Record at 24-bit / 48 kHz minimum (24-bit provides 144 dB dynamic range, eliminating the need to record hot)
- Monitor with headphones (closed-back to prevent bleed into the mic)

## Room and Acoustic Treatment

### Recording Environment Checklist

| Factor | Ideal | Acceptable | Avoid |
|--------|-------|-----------|-------|
| Room size | Medium (10×12 ft or larger) | Small treated room | Untreated bathroom or hallway |
| Reflection control | Absorption panels on walls behind and beside singer | Portable vocal shield (gobo) | Bare parallel walls (flutter echo) |
| Noise floor | < -60 dBFS | < -50 dBFS | HVAC hum, traffic, electronics |
| Floor | Carpeted or rug-covered | Hard floor with area rug | Bare tile (reflective) |

### Microphone Placement

| Technique | Distance | Effect |
|-----------|----------|--------|
| Close (2-6 inches) | Intimate, detailed, proximity effect boost | Pop/R&B vocals, ASMR, podcast |
| Standard (6-12 inches) | Balanced, natural | Most studio vocal recording |
| Far (12-24 inches) | Airy, room ambience included | Choir, ensemble, classical |

### Pop Filter and Shock Mount

- **Pop filter**: Place 2-4 inches from the mic capsule to reduce plosives (P, B, T sounds)
- **Shock mount**: Isolates the mic from stand vibrations and handling noise
- Both are essential for professional vocal recording

## Recording Session Workflow

### Pre-Session

1. Test all equipment (mic, cable, preamp, headphones) 30 minutes before the session
2. Set headphone mix: vocalist needs to hear themselves clearly with minimal latency
3. Record 30 seconds of room tone for noise reduction reference
4. Set input gain with the vocalist singing their loudest passage — peaks should reach -12 to -6 dBFS

### During the Session

1. Record full takes first (3-5 complete performances)
2. Then record punch-ins for specific problem sections
3. Record doubles (second performance layered for thickness) if the genre calls for it
4. Record ad-libs and harmonies as separate tracks
5. Take breaks every 45-60 minutes to protect the vocalist's voice

### Post-Session

1. Label and organize all takes immediately
2. Create a comp (composite take) from the best sections of each full take
3. Back up the session to a second drive
4. Note any technical issues for the mixing engineer (noise, bleed, proximity effect)

## Common Problems and Solutions

| Problem | Cause | Solution |
|---------|-------|----------|
| Sibilance (harsh S sounds) | Bright mic + close placement | Angle mic slightly off-axis, use de-esser in mix |
| Plosives (P/B pops) | Direct air hitting the diaphragm | Better pop filter placement, sing slightly off-axis |
| Room echo | Untreated reflective surfaces | Add absorption, use a closer mic technique |
| Thin sound | Too much distance, wrong mic | Move closer (proximity effect), try a different mic |
| Headphone bleed | Loud headphone mix leaking into mic | Lower headphone volume, use closed-back headphones |
