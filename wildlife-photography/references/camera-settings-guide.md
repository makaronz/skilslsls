# Wildlife Camera Settings Guide

Optimize camera settings for various wildlife photography scenarios.

---

## Core Settings by Scenario

### Birds in Flight (BIF)

| Setting | Value | Rationale |
|---------|-------|-----------|
| Mode | Shutter Priority or Manual | Control speed |
| Shutter Speed | 1/2000 - 1/4000s | Freeze wing motion |
| Aperture | f/5.6 - f/8 | Balance sharpness and DOF |
| ISO | Auto (100-6400) | Let camera adjust |
| Drive | High-speed continuous (10-20fps) | Maximize captures |
| AF Mode | Continuous (AF-C/AI Servo) | Track moving subject |
| AF Area | Wide/tracking or dynamic area | Let camera find and track |
| Metering | Matrix/evaluative | Handle varied backgrounds |

### Static Wildlife (Perched, Resting)

| Setting | Value | Rationale |
|---------|-------|-----------|
| Mode | Aperture Priority | Control DOF |
| Aperture | f/4 - f/5.6 | Isolate subject, bokeh |
| Shutter Speed | 1/500s minimum | Account for subject movement |
| ISO | Auto (100-3200) | Minimize noise |
| AF Mode | Single (AF-S) | Lock focus precisely |
| AF Area | Spot / Eye detect | Focus on eye |
| Metering | Spot on subject | Accurate exposure |

### Mammals in Motion

| Setting | Value | Rationale |
|---------|-------|-----------|
| Mode | Shutter Priority | Control motion freeze |
| Shutter Speed | 1/1000 - 1/2000s | Freeze running motion |
| Aperture | f/4 - f/8 | Open for speed, DOF for groups |
| ISO | Auto (100-6400) | Balance noise and speed |
| Drive | High continuous | Action sequences |
| AF Mode | Continuous | Track movement |
| AF Area | Zone/group | Cover subject area |

## Metering Strategies

### Metering Mode Selection

| Situation | Metering Mode | Compensation |
|-----------|--------------|-------------|
| Even lighting | Matrix/Evaluative | ±0 |
| Backlit subject | Spot on subject | +1 to +2 EV |
| White bird on blue sky | Matrix | +0.5 to +1 EV |
| Dark subject, bright BG | Spot on subject | -0.5 to -1 EV |
| Snow or sand | Matrix | +1 to +2 EV |

## Image Format and Quality

| Format | Pros | Cons | When to Use |
|--------|------|------|-----------|
| RAW only | Maximum editing flexibility | Large files, slow buffer | Primary format |
| RAW + Small JPEG | RAW for editing, JPEG for quick review | Uses more buffer | Field review needed |
| JPEG only | Fast buffer, small files | Limited recovery | Not recommended |

### Buffer Management
- High-speed shooting fills buffer quickly
- Use fastest card available (CFexpress Type B > V90 SD)
- Shoot in short bursts (3-5 frames) rather than holding down
- Check buffer capacity: know how many shots before slowdown

## White Balance

| Condition | White Balance Setting | Kelvin |
|-----------|---------------------|--------|
| Sunny | Daylight | 5200K |
| Cloudy | Cloudy | 6000K |
| Shade | Shade | 7000K |
| Golden hour | Daylight (preserve warmth) | 5200K |
| Overcast forest | Cloudy or custom | 6000-6500K |

**Recommendation:** Shoot RAW and set white balance in post-processing for maximum flexibility.

## Custom Function Recommendations

| Function | Setting | Purpose |
|----------|---------|---------|
| Back-button AF | Assign AF to rear button | Separate focus from shutter |
| Auto ISO minimum speed | 1/focal length × 2 | Auto-maintain sharp speed |
| Focus limiter | Set to expected range | Faster AF acquisition |
| Highlight warning | Enable (blinkies) | Prevent blown highlights |
| Image review | Off or 2 seconds | Save battery, stay ready |
| Silent shutter | Enable for sensitive subjects | Reduce disturbance |
