# E-commerce Photography Guide

Produce platform-compliant product images that maximize conversion rates.

---

## Platform Requirements

### Amazon

| Requirement | Specification |
|-------------|-------------|
| Main image background | Pure white (RGB 255,255,255) |
| Minimum resolution | 1000px on longest side (2000px recommended) |
| File format | JPEG, TIFF, PNG, GIF |
| Max file size | 10MB |
| Product fill | 85% of frame |
| No text/logos | On main image |
| Allowed angles | Front, back, side, detail, lifestyle |
| Image count | Up to 9 (7 recommended minimum) |

### Shopify
| Requirement | Specification |
|-------------|-------------|
| Recommended size | 2048×2048px (square) |
| Max file size | 20MB |
| Format | JPEG, PNG, GIF, WebP |
| Aspect ratio | Consistent across products |
| Background | Flexible (white, lifestyle, custom) |

### General E-commerce Best Practices
- Consistent lighting and style across all products
- Multiple angles: front, back, side, detail, scale reference
- Lifestyle/context images increase conversion 20-30%
- Show size/scale with common reference objects
- Include detail shots of texture, stitching, labels
- Consistent white balance across all images

## Workflow

### Shooting Workflow
1. **Prep**: Clean product, remove tags/stickers, steam wrinkles
2. **Setup**: Position on sweep, set lighting, tether camera
3. **Test shots**: Check exposure, white balance, focus
4. **Hero shot**: Front view, critical composition
5. **Variations**: Back, sides, angles per shot list
6. **Details**: Swap to macro or close-focus, adjust lighting
7. **Lifestyle**: Change set, add props, adjust lighting mood

### Post-Processing Workflow
1. **Select**: Choose best images per angle
2. **Global adjustments**: White balance, exposure correction
3. **Background**: Remove/clean to pure white (if required)
4. **Retouching**: Remove dust, scratches, sensor spots
5. **Color accuracy**: Match to physical product
6. **Crop and resize**: Platform-specific dimensions
7. **Export**: Appropriate format, compression, color space (sRGB)

## Conversion Optimization

### Image Strategies That Increase Sales

| Strategy | Impact on Conversion | Implementation |
|----------|---------------------|----------------|
| 360° view or video | +27% average | Turntable, 36-72 images |
| Lifestyle images | +22% average | Product in context |

| Model/human reference | +15% average | Show scale, use case |
| Infographic images | +12% average | Callouts, dimensions, features |

## Equipment Recommendations

### Budget Setup ($200-500)
- Camera: Smartphone with manual mode
- Light: Two LED panels or window light + reflector
- Background: White poster board or fabric sweep
- Tripod: Basic with phone mount
- Editing: Free software (GIMP, Lightroom mobile)

### Professional Setup ($2,000-5,000)
- Camera: Mirrorless or DSLR (24MP+)
- Lenses: 50mm f/1.8 + 100mm macro
- Lights: 2-3 studio strobes or continuous LED
- Modifiers: Softbox, strip box, reflectors
- Background: Paper sweep + shooting table
- Tethering: Laptop with Capture One or Lightroom
