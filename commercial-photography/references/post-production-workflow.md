# Commercial Post-Production Workflow

Efficient pipeline for commercial photography post-processing.

---

## Pipeline

```
Capture (tethered) -> Cull -> RAW Process -> Retouch -> Grade
  -> Composite -> Client Review -> Revisions -> Export -> Archive
```

## Time Estimates

| Project | Shot | Delivered | Post/Image | Total |
|---------|------|-----------|-----------|-------|
| Product (white BG) | 50-200 | 30-100 | 5-10 min | 4-16h |
| Lifestyle | 200-500 | 20-50 | 10-20 min | 4-16h |
| Headshots | 50-150 | 10-30 | 10-15 min | 2-8h |
| Campaign hero | 200-500 | 5-15 | 30-90 min | 3-22h |

## Culling System

| Rating | Meaning | Action |
|--------|---------|--------|
| Reject | Soft focus, bad expression | Delete |
| 1 star | Possible selection | Review |
| 3 stars | Client selects | Full process |
| 5 stars | Hero images | Maximum attention |

## Batch Processing
1. Edit first image of each setup
2. Sync settings to all similar images
3. Adjust individual images as needed
4. Export with consistent preset

## Client Review
- Present on gallery platform (Pixieset, ShootProof)
- Watermarked low-res proofs
- 2-3 revision rounds included
- Document all changes in writing

## File Management
```
Projects/YYYY/YYYY-MM-DD_Client_Project/
  01_RAW/ | 02_Selects/ | 03_Retouched/ | 04_Finals/ | 05_Delivered/
```

Archive RAW files 3-5 years, final deliverables indefinitely.
