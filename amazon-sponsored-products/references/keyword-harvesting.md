## Amazon Platform Overview

Understanding Amazon's advertising ecosystem is essential for effective keyword harvesting. The platform offers unique capabilities that differentiate it from other advertising channels.

### Platform Strengths

- **Audience reach**: Access to Amazon's user base with granular targeting options
- **Ad format variety**: Multiple creative formats optimized for the platform's user experience
- **Data signals**: Rich first-party data for audience building and optimization
- **Measurement tools**: Native attribution and reporting capabilities
- **API access**: Programmatic campaign management and automation

## AR Creative Development

### AR Ad Types

| Type | Description | Engagement Rate | Complexity |
|------|------------|----------------|------------|
| Face filter | Overlays on user's face | High | Medium |
| World effect | Places objects in environment | Medium-High | High |
| Try-on | Virtual product try-on | Very High | High |
| Game lens | Interactive mini-games | Very High | Very High |
| Marker-based | Triggered by scanning an image | Medium | Medium |

### Development Workflow

1. **Concept and storyboard**: Define the AR experience and user interaction flow
2. **Asset creation**: Design 3D models, animations, and textures
3. **Lens/Filter development**: Build in Lens Studio or equivalent tool
4. **Testing**: Test on multiple devices and lighting conditions
5. **Optimization**: Reduce file size, improve loading speed
6. **Submission**: Submit for platform review and approval
7. **Launch and monitoring**: Track engagement, shares, and play time

### Performance Optimization

- **File size**: Keep under platform limits for fast loading
- **Frame rate**: Target 60fps for smooth experience
- **Battery impact**: Minimize computational complexity
- **Accessibility**: Provide non-AR fallback for unsupported devices
- **Tracking stability**: Ensure face/world tracking remains stable

### Measurement

- **Plays**: Number of times the AR experience was opened
- **Play time**: Average duration of interaction
- **Shares**: Number of times users shared the AR content
- **Saves**: Number of times the lens/filter was saved
- **Conversion lift**: Impact on downstream conversions vs. non-AR ads

## Common Pitfalls and How to Avoid Them

| Pitfall | Why It Happens | How to Avoid |
|---------|---------------|---------------|
| Analysis paralysis | Too much data, not enough action | Set decision deadlines, use frameworks |
| Premature scaling | Scaling before validating | Prove ROI at small scale first |
| Ignoring data | Relying on gut feelings | Build data review into process |
| Tool overload | Adding tools without strategy | Audit tool stack quarterly |
| Siloed execution | Teams working independently | Regular cross-functional syncs |
| Inconsistent measurement | Different teams, different metrics | Standardize KPI definitions |
| Set-and-forget | Launching without ongoing optimization | Schedule regular optimization reviews |
