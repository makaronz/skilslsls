# Color Gel Work

Color theory, color management, and color grading principles for video lighting, lighting design, and illumination techniques for film and video.

---

## Color Fundamentals

Color profoundly influences perception, emotion, and communication in video lighting, lighting design, and illumination techniques for film and video. Understanding color theory and management ensures consistent, intentional results across production and delivery.

### Color Properties

| Property | Description | Application |
|---|---|---|
| Hue | The color itself (red, blue, green) | Identity, mood, meaning |
| Saturation | Color intensity/purity | Energy, realism, style |
| Brightness/Value | Light to dark range | Depth, focus, contrast |
| Temperature | Warm to cool spectrum | Mood, time, atmosphere |

## Color Theory Basics

### Color Relationships

- **Complementary** — Colors opposite on the color wheel (high contrast, visual tension)
- **Analogous** — Colors adjacent on the wheel (harmony, cohesion)
- **Triadic** — Three equally spaced colors (vibrant, balanced diversity)
- **Monochromatic** — Variations of a single hue (unified, elegant)

### Color Psychology

| Color | Associations | Common Uses |
|---|---|---|
| Red | Energy, urgency, passion | Alerts, CTAs, emotion |
| Blue | Trust, calm, professionalism | Corporate, technology |

| Yellow | Optimism, attention, warmth | Highlights, warnings, energy |
| Purple | Luxury, creativity, wisdom | Premium, creative, spiritual |

## Color Management

### Maintaining Consistency

- **Define color palettes** — Establish approved colors with specific values (hex, RGB, CMYK)
- **Calibrate displays** — Ensure monitors display colors accurately
- **Use color profiles** — Apply appropriate ICC profiles for each delivery medium
- **Test across devices** — Verify color appearance on different screens and output formats

### Color Spaces

| Color Space | Use Case | Gamut |
|---|---|---|
| sRGB | Web, digital screens | Standard |
| Adobe RGB | Print preparation | Extended |
| Rec. 709 | HD video | Standard |
| DCI-P3 | Cinema, HDR displays | Wide |
| Rec. 2020 | HDR video | Ultra-wide |

## Color Grading for Video

### Grading Workflow

1. **Balance** — Correct white balance and exposure for neutral starting point
2. **Match** — Ensure consistency across all shots in a sequence
3. **Style** — Apply creative look and color treatment
4. **Refine** — Make selective adjustments to specific elements
5. **Deliver** — Export with appropriate color space for the target platform

### Best Practices

- Always work with the highest-quality source material available
- Grade on a calibrated monitor in a controlled viewing environment
- Make global adjustments before selective corrections
- Use reference images to maintain consistency across sessions
- Preserve skin tones as a priority — audiences are most sensitive to these
